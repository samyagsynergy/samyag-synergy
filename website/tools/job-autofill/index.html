Free Chrome Extension

Job Application AutoFill

Auto-fill LinkedIn Easy Apply, Workday, Greenhouse, and Lever. Set up your profile once, then it fills every field as you click through application steps.

⬇️ Download Extension
1
Download & Extract

Click the button above to download the .zip file. Extract it to a folder on your computer.

2
Build Your Profile

Open the Profile Builder → fill the form → click Generate → Copy → paste into the profile.json file inside the downloaded folder → save.

3
Install in Chrome

Open chrome://extensions/ → turn on Developer mode → click Load unpacked → select the extension folder.

Green = from your profile
Orange = review before submit
Red = EEO (fill manually)
Tip: If a field ever misses, click the puzzle piece icon → Fill Current Page.

Privacy: 100% local. No accounts, no cloud, no data leaves your browser.
